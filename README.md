# 线路规划平台

自驾路线规划与展示平台：多路线管理、逐日行程、四季壁纸主页（液态玻璃风格）、路线编辑器。

## 在线预览

[sunyh-gi.github.io/route-planner](https://sunyh-gi.github.io/route-planner/)

## 主要功能

- **多路线管理**：主页画廊列出全部路线，点击卡片进入查看
- **逐日行程**：途经点按天分色标注，进入后自动取景
- **地图展示**：路径经 OSRM 规划，驾车 / 步行 / 骑马段以不同线型区分
- **路线编辑**：桌面端可搜索地点、添加站点、拖拽排序、重命名并保存
- **四季壁纸主页**：按东八区季节自动切换壁纸
- **移动端只读**：手机端仅浏览，编辑入口保留在桌面端
