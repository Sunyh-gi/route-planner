# 路线规划平台（Route Planner）

基于 Leaflet 的「**壳 + 外置数据**」路线规划平台：打开先看到路线库画廊，进入路线后可在地图上搜索地名 / 点选坐标加站、按天编排、自动补全驾车路径，并把结果保存回 GitHub 仓库。

**线上地址：https://sunyh-gi.github.io/route-planner/**

- 数据真源在 GitHub 仓库：每条路线一份 `routes/<id>.js` + 共享目录 `routes/catalog.js`，多设备打开即见最新
- HTML 本体（约 158 KB）不携带任何路线数据，新增路线无需改动 HTML
- 单文件壳 + 相对路径加载数据，`file://` 直接双击可用，也可部署到任意静态托管

## 目录结构

```
index.html              ← 站点入口：根路径自动跳转到平台页
线路规划平台.html        ← 平台壳（渲染器 + 主页画廊 + 侧栏编辑器，无路线数据）
routes/
  catalog.js            ← 路线目录（id / 名称 / 数据文件 / 天数 / 点数 / 主色 / 季节）
                          + 内置地名库（离线搜索兜底）
  cx.js                 ← 川西路线数据（坐标已预转 WGS-84）
  yl.js                 ← 伊犁环线数据
assets/
  home-bg.jpg           ← 主页壁纸
  lonely-travel-logo-white.png  ← 主页标识
```

## 使用

- **本地**：双击 `线路规划平台.html`（`file://` 下按相对路径加载 `routes/*.js`，无需起服务）
- **线上**：把 HTML 与 `routes/` 保持同目录一起发布（GitHub Pages / 任意静态托管）
- ⚠ 不要把 HTML 单独拷走，否则 `routes/catalog.js` 与 `routes/*.js` 缺失，主页为空

## 界面用法

**主页画廊（四季分组）**：全屏壁纸打底，左上角为品牌标识（`assets/lonely-travel-logo-white.png`，白色版），路线按春夏秋冬四个板块从上到下排列（归属读目录条目的 `season` 字段，未登记默认归春），空季节显示「静待规划」虚线占位卡。滚轮只滚动卡片层，卡片上移时渐隐融入壁纸。每张卡显示路线名 + 「X 天 X 晚」。顶部三件套：＋ 新建 / ⚙ 设置 / 🔄 刷新。

**四季壁纸（v6.13）**：按东八区日期自动分季选用（春 3-5 月 / 夏 6-8 月 / 秋 9-11 月 / 冬 12-2 月），每分钟核验跨季自动切换；当季清单为空时回落到第一个有图的季节。**点击左上角 logo** 可在当季壁纸间循环切换（淡入淡出），每季选中的序号记忆在浏览器本地。加新壁纸：把 2560px 宽 JPEG 放进对应季节目录，并在 `assets/wp/manifest.js` 对应数组按序追加一行。

**进入路线**：点卡片即从下方滑入路线界面（返回时反向滑回），地图自动取景到该路线范围（按视口留白计算，并水平补偿左侧面板宽度，路线在可见区内视觉居中）。

**视图 / 编辑双模**：进入路线默认**视图模式**，只显示路线名、⋯ 菜单与各天地点列表（点行飞往该标记）。点 ⋯ → **编辑路线** 切换到编辑模式：出现搜索栏、保存按钮，以及每行的行内操作（✎ 改名 / ↑↓ 换位 / ◀▶ 换天 / ✕ 删除）与整行拖拽换天。新建路线直接进入编辑模式。修改后保存按钮高亮。

**加站**：搜索结果行点击，或直接点地图空白处 → 在该坐标出现青色「＋」预览点，右侧弹出玻璃卡片「添加到第几天？」，点某天即加入（卡片底部提示「点地图可换位置」）。GPS 坐标粘贴同样可用。

**按天编排**：每天一个颜色，取自 30 色全局调色板（色轮柔和蓝 → 柔紫 → 柔红），同路线内相邻天颜色明显区分；相邻地点间自动用 OSRM 公共接口补全驾车路径，失败时保留虚线占位，支持步行 / 骑行段（虚线 + 🚶 / 🚲 图标）。

**浏览器前进 / 后退**：状态写入地址栏 hash（`#/` 主页 · `#/n` 新建 · `#/r/<id>` 进入路线，设置弹层在任意页附加 `/s`），返回键可退回，F5 刷新停留在当前路线；离开含未保存修改的页面会弹确认。

## 外置路线数据格式（`routes/<id>.js`）

```js
(function(){window.ROUTE_PACKS=window.ROUTE_PACKS||{};window.ROUTE_PACKS["<id>"]={
  id: "<id>",
  name: "显示名",
  stops: [ { name: "乌鲁木齐", lat: 43.91279, lng: 87.46644, day: 1, tag: "" }, ... ],
  segs: {
    "43.91279,87.46644|44.97102,81.02588": { d: 581929, m: 396, poly: [ [lat,lng], ... ] }
    // 可选 p: "foot" | "cycling" —— 该段画虚线并显示 🚶/🚲 图标
  },
  preset: { c: 0, tag: "⛰️" }    // 可选：c = 30 色索引；tag ≤ 8 字符
};})();
```

新增路线：写好 `routes/<id>.js` + 在 `catalog.js` 登记一条（含 `season` 归属季节）即可。

> **坐标统一 WGS-84**。GCJ-02 采集的源数据需先转换为 WGS-84；OSM / OSRM / Thunderforest / Esri 均为 WGS-84，可直接对齐。`poly` 为该段完整轨迹缓存（无缓存也能画虚线并在线补全）。

## 地名搜索 Key（可选）

高德 Web 服务 Key 用于全国地名搜索：

1. [console.amap.com](https://console.amap.com) → 应用管理 → 创建应用 → 添加 Key（类型选「Web 服务」）
2. 平台内 ⚙ 设置 → 粘贴 Key → 保存
3. 浏览器端直接调用（高德允许 CORS），坐标自动由 GCJ-02 转为 WGS-84

> Key 仅保存在本机浏览器 localStorage，不会上传；无 Key 时可用内置地名库离线匹配（`routes/catalog.js` 的 `ROUTE_PLACES`）。

## 保存到 GitHub 仓库

平台把仓库作为数据真源，所有写入都通过 Contents API（写文件前先取 sha，实现「先读后写」覆盖），并自动同步维护 `catalog.js`：

1. github.com → Settings → Developer settings → Personal access tokens → 新建 Token（classic 或 fine-grained），**勾 `repo` 权限**
2. 平台内 ⚙ 设置 → **GitHub Token** 框粘贴 → 保存
3. **测试**：远端目录存在则提示条目数，不存在则提示「保存任意路线时会自动创建」
4. **保存** → `PUT routes/<id>.js` + `PUT routes/catalog.js`
5. **删除** → `DELETE routes/<id>.js` + 推一次目录
6. **🔄 刷新**（主页按钮）→ 从仓库拉目录，按需补拉本机缺少的路线
7. **⇪ 迁移旧路线** → 把旧版本地数据逐条入库后清空本地旧库
8. 启动时若已配置 Token 会自动同步远端目录，弱网 / 离线时降级用本地只读缓存

> **Token 只保存在本机浏览器 localStorage，不会上传**，无 Token 时仅可浏览与编辑（保存 / 删除会被拦截并引导设置）。
> 写入能力等价于仓库写权限，请使用最小权限的专用 Token，并可在 github.com 随时撤销。

## 设计令牌速查

界面为统一的「白玻璃」体系（清透来自透明度而非色彩对比），新增元素请沿用同族配方：

- **L1 浮层小件**（按钮 / 菜单 / 提示 / pill）：白 .08–.10 + `blur(1px)` + 细白边框 .32 + 顶缘受光
- **L2 内容玻璃**（弹窗 / 表单载体）：白 .40 + `blur(32px)`；输入框白 .28（聚焦 .45）；轻按钮 .32
- **L3 主页卡片**（壁纸大卡）：白 .05 + 极轻边缘折射（SVG feDisplacementMap，无光学叠加）+ 受光四件套
- **路线页元素**（面板 / 详情卡 / 底图选择 / 缩放钮 / 加站日卡）：白 .10 + `blur(8px)`，不加折射
- 受光四件套 = 顶缘 1px 高光 + 顶内侧柔光带 + 下缘次高光 + 极淡中性托影；不使用彩色投影与文字阴影
- 深色底图（卫星 / NatGeo）下统一为白玻璃 + 白字

## 技术栈

- Leaflet 1.9.4（CDN）+ 原生 JS 单文件壳；路线数据按需 `<script>` 注入加载（`file://` 与 http 双通）
- 路径规划走 OSRM 公共接口（浏览器端并发 2、按坐标缓存）；地名搜索走高德 Web 服务
- 页面切换用 **View Transitions API** 做整屏上下滑动转场（750ms，自动适配「减少动态效果」偏好，不支持的浏览器直接切换）
- 数据持久化：GitHub 仓库为唯一真源；localStorage 仅存设置与离线只读快照
